# Rock vs Mine Prediction using Machine Learning

## Project Overview
This project uses Machine Learning techniques to classify sonar signals and predict whether the detected underwater object is a Rock or a Mine.

The project uses the Sonar dataset to train a classification model that learns patterns from sonar signal data and makes predictions based on input features.

## Technologies Used
- Python
- NumPy
- Pandas
- Scikit-learn
- Google Colab
- Machine Learning

## Objective
To develop a machine learning classification system that distinguishes between rocks and mines using sonar signal measurements.
